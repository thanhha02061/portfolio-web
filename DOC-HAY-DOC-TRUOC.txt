PORTFOLIO THANH HÀ — thanhha-portfolio.netlify.app
===================================================

TRONG THƯ MỤC NÀY
-----------------
sua.html     <- MỞ FILE NÀY để sửa nội dung (không cần biết code)
index.html   <- website thật, do sua.html tạo ra
images/      <- bỏ ảnh vào đây


SỬA NỘI DUNG — 4 BƯỚC
----------------------
1. Double-click sua.html  (mở bằng Chrome)
   Nếu đã có file noi-dung.json từ lần trước:
   bấm "Nạp nội dung đã lưu" -> chọn file đó

2. Gõ vào các ô bên trái. Bản xem trước bên phải đổi theo ngay.

3. Bấm 2 nút:
   "Lưu nội dung (.json)"  -> giữ file này để lần sau sửa tiếp
   "Tải index.html"        -> file mới trong thư mục Downloads

4. Chép index.html vừa tải vào thư mục này (đè lên file cũ),
   rồi kéo CẢ THƯ MỤC lên Netlify (tab Deploys).

LƯU Ý
-----
- Kéo CẢ THƯ MỤC lên Netlify, đừng kéo riêng index.html (sẽ mất ảnh).
- File sua.html cũng được đưa lên mạng cùng. Nó chỉ là cái form,
  không chứa gì bí mật. Không thích thì xoá nó khỏi thư mục
  trước khi kéo lên Netlify.
- Site đang ở chế độ Private. Người ngoài chưa xem được.
  Khi nào nội dung xong: Netlify -> Project configuration ->
  Project visibility -> Edit visibility -> Public.
