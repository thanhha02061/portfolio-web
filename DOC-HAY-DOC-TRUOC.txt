PORTFOLIO THANH HÀ — thanhha-portfolio.pages.dev
================================================

TRONG THƯ MỤC NÀY
-----------------
sua.html     <- MỞ FILE NÀY để sửa nội dung (không cần biết code)
index.html   <- website thật, do sua.html tạo ra
images/      <- bỏ ảnh vào đây


SỬA NỘI DUNG — 4 BƯỚC
----------------------
1. Double-click sua.html  (mở bằng Chrome)
   Nếu đã có file noi-dung.json từ lần trước:
   bấm "Nạp nội dung đã lưu" -> chọn file đó

2. Gõ vào các ô bên trái. Bản xem trước bên phải đổi theo ngay.

3. Bấm 2 nút:
   "Lưu nội dung (.json)"  -> giữ file này để lần sau sửa tiếp
   "Tải index.html"        -> file mới trong thư mục Downloads

4. Chép index.html vừa tải vào thư mục này (đè lên file cũ),
   rồi mở GitHub Desktop: Commit to main -> Push origin.
   Khoảng 1 phút sau web tự cập nhật (Cloudflare Pages).

LƯU Ý
-----
- Commit cả ảnh trong images/ cùng lúc với index.html.
- sua.html cũng nằm trên web. Nó chỉ là cái form, không chứa gì bí mật.
- Link Cloudflare mặc định public: nội dung chưa xong thì chưa gửi link cho ai.
- Lỡ hỏng: Cloudflare -> Deployments -> Rollback,
  hoặc GitHub Desktop -> History -> Revert changes in commit.
